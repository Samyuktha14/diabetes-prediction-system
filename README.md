# 🩺 Diabetes Prediction System

A machine learning-based web application that predicts the likelihood of diabetes in individuals based on various health parameters.

---

## 🧠 Project Overview

This project uses machine learning algorithms to predict diabetes risk. Users can input health information such as age, BMI, glucose level, and more, and the system predicts the likelihood of diabetes in real-time.

The app is deployed on **Streamlit**, allowing easy access via a web browser.

---

## 🛠️ Tech Stack

- **Backend & ML:** Python, scikit-learn, pandas, numpy  
- **Web App:** Streamlit  
- **Machine Learning Model:** K-Nearest Neighbors (KNN), Support Vector Classifier (SVC), Naive Bayes Classifier  

---

## ⚡ Features

- Predicts the likelihood of diabetes based on user input.  
- Interactive and user-friendly web interface using Streamlit.  
- Uses multiple machine learning algorithms for accurate predictions.  
- Displays prediction results instantly after submitting inputs.
